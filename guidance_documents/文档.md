# Lite-Scheduler Core 模块详细文档

## 1. 模块概述

Lite-Scheduler 是一个轻量级的任务调度框架，提供了基于注解和编程式两种任务定义方式，支持 Cron 表达式和固定频率调度，具备任务持久化、执行日志记录、插件扩展等功能。

### 3.2 注解定义

#### TubaTask.java

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface TubaTask {
    String name() default "";
    String cron() default "";
    long interval() default -1;
    TimeUnit type() default TimeUnit.MILLISECONDS;
    boolean async() default false;
    String group() default "default";
    String description() default "";
    int repeatCount() default -1;
}
```

**功能**：
- 定义 `@TubaTask` 注解，用于标记需要调度的方法
- 支持两种调度方式：Cron 表达式和固定时间间隔
- 支持配置任务名称、分组、异步执行、执行次数等属性
- 默认不异步执行（`async() default false`）
- 默认无限循环执行（`repeatCount() default -1`）

## 4. 组件间交互流程

### 4.1 任务注册流程

1. **应用启动**：`SchedulerCoreApplication` 启动，初始化 Spring 容器
2. **配置加载**：`ExecutorConfiguration` 加载配置属性
3. **组件初始化**：所有 Spring 组件被实例化，包括 `TaskRegistry`、`Scheduler` 等
4. **任务扫描**：`TaskRegistrar` 扫描所有 Spring Bean 中的 `@TubaTask` 注解方法
5. **任务恢复**：`TaskRecovery` 从数据库加载持久化任务
6. **任务注册**：所有任务被注册到 `TaskRegistry`
7. **任务调度**：`Scheduler` 调度所有注册的任务

### 4.2 任务执行流程

1. **任务触发**：`Scheduler` 根据调度配置触发任务执行
2. **创建上下文**：创建 `TaskContext`，包含任务定义和执行信息
3. **插件 before**：`PluginManager` 调用所有插件的 `before` 方法
4. **任务执行**：`SimpleTaskExecutor` 执行任务方法（同步或异步）
5. **记录日志**：`TaskLogService` 记录任务执行状态
6. **更新定义**：`TaskPersistenceService` 更新任务的 `lastFireTime`
7. **插件 after/onError**：`PluginManager` 调用所有插件的 `after` 或 `onError` 方法

## 5. 总结

Lite-Scheduler Core 模块提供了一个完整的任务调度框架，具有以下特点：

1. **灵活的任务定义方式**：支持基于注解和编程式两种任务定义方式
2. **多种调度策略**：支持 Cron 表达式、固定频率和固定延迟调度
3. **任务持久化**：支持将任务定义和执行日志持久化到数据库
