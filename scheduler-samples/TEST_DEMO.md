# 任务执行器功能测试 Demo

## 概述

本测试 Demo 全面演示了任务执行器的三个核心功能：
1. **任务实例依赖注入**：利用 Spring 的依赖注入创建任务实例
2. **任务执行超时控制**：防止任务长时间占用资源
3. **任务失败重试机制**：提高任务执行可靠性

## 测试文件说明

### 1. TestService.java
- **功能**：测试服务类，提供 `getMessage()` 方法
- **用途**：用于演示依赖注入功能

### 2. DependencyInjectionTestTask.java
- **功能**：依赖注入测试任务
- **特点**：
  - 使用 `@Component` 注解注册到 Spring 容器
  - 通过 `@Autowired` 注入 `TestService`
  - 执行时间为 1 秒

### 3. TimeoutTestTask.java
- **功能**：超时测试任务
- **特点**：
  - 执行时间为 10 秒
  - 用于测试超时控制机制

### 4. RetryTestTask.java
- **功能**：重试测试任务
- **特点**：
  - 前 2 次执行失败
  - 第 3 次执行成功
  - 用于测试失败重试机制

### 5. TaskTestDemo.java
- **功能**：测试主类
- **特点**：
  - 实现 `ApplicationRunner` 接口
  - 应用启动时自动执行测试
  - 依次执行三个测试

## 配置说明

### application.yml 配置

```yaml
lite-scheduler:
  executor:
    pool-size: 10                      # 线程池大小
    scheduler-pool-size: 5             # 调度器线程池大小
    thread-name-prefix: lite-scheduler- # 线程名称前缀
    task-timeout: 60000                # 默认任务超时时间（毫秒）
    shutdown-timeout-seconds: 30       # 执行器关闭超时时间（秒）
    force-shutdown-timeout-seconds: 10 # 强制关闭超时时间（秒）
    default-retry-count: 0             # 默认重试次数
    default-retry-interval: 1000       # 默认重试间隔（毫秒）
```

### 配置优先级

1. **任务级别配置**：注册任务时传入的配置参数
2. **全局配置**：application.yml 中的配置
3. **默认值**：代码中设置的默认值

## API 使用示例

### 基本使用

```java
// 创建任务定义
TaskDefinition definition = new TaskDefinition();
definition.setId("task-1");
definition.setName("My Task");

// 注册任务（使用默认配置）
String taskId = taskSchedulerService.registerTask(myTask, definition);
```

### 使用配置

```java
// 注册任务（带配置）
String taskId = taskSchedulerService.registerTask(
    myTask, 
    definition,
    30000L,  // 超时时间：30 秒
    3,       // 重试次数：3 次
    2000L    // 重试间隔：2 秒
);
```

### 使用 Cron 表达式

```java
// 注册 Cron 任务（带配置）
String taskId = taskSchedulerService.registerTask(
    myTask, 
    "0 0 * * * ?",  // Cron 表达式
    60000L,  // 超时时间：60 秒
    2,       // 重试次数：2 次
    1000L    // 重试间隔：1 秒
);
```

## 验证改进效果

### 1. 依赖注入验证
- **改进前**：直接使用 `Class.forName().newInstance()` 创建任务实例，无法注入依赖
- **改进后**：优先从 Spring 容器获取 Bean，支持依赖注入
- **验证方法**：查看日志中是否显示 "使用依赖注入的服务：Hello from TestService!"

### 2. 超时控制验证
- **改进前**：无超时控制，任务可能长时间占用资源
- **改进后**：支持配置超时时间，超时后自动取消任务
- **验证方法**：查看任务是否在指定时间后被中断

### 3. 重试机制验证
- **改进前**：无重试机制，任务失败后需要手动重新触发
- **改进后**：支持配置重试次数和间隔，自动重试
- **验证方法**：查看失败任务是否自动重试并成功

## 故障排查

### 问题 1：依赖注入失败
- **现象**：任务执行时 `testService` 为 null
- **原因**：任务类未使用 `@Component` 注解
- **解决**：确保任务类使用 `@Component` 注解

### 问题 2：超时控制不生效
- **现象**：任务执行超过配置的超时时间仍未中断
- **原因**：任务未设置为异步执行或配置未生效
- **解决**：检查 `definition.setAsync(false)` 和配置值

### 问题 3：重试机制不生效
- **现象**：任务失败后未自动重试
- **原因**：重试次数配置为 0 或配置未生效
- **解决**：检查 `definition.setRetryCount(n)` 配置
